## 文档约定

- 所有示例代码都是**可以编译的完整片段**，不是伪代码；复制后补 import 即可。
- 接口示例默认已登录（`Authorization: Bearer <token>`），登录方式见 05。
- 提到"重启"指重启 Spring Boot 进程；模型变更靠启动时的 `synchronizeSchema` 生效。
- 版本：`1.0.0`，对应 `pom.xml` 的 `<version>`。
